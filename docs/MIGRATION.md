# Archive link migration and reconciliation

Updated 5 November 2026. The current archive is live at https://archive.museumofone.art/ and its shared native explorer is integrated at https://www.museumofone.art/digital-archive-library/.

All 118 published public Ghost content records and all 125 sitemap pages were checked after the authorized migration: no retired service name or address remains in the current fields/pages inspected. Existing page structure and original article prose were retained; archive badges, an iframe fallback, one research-page link, two header metadata fields and obsolete archive/charter wording were updated. Private before/after evidence and historical URLs are retained outside this public repository.

General library navigation leads to the new root. Unmatched former items use explicitly labelled title searches, never an assertion of exact record equivalence. Retired `sameAs` values were removed rather than replaced with search URLs. A historical numeric record identifier remains qualified as “Previous catalogue record”. Working-paper links use verified title/DOI contexts.

The selected archive comprises 16 public Zenodo records, original source snapshots and byte-verified PDF access copies. It does not establish complete recovery of the previous catalogue, its database, omitted records or permissions. No redirect at the former host is claimed.

## External audit

The 24 identified Wikidata entities contain no retired address in their claims, qualifiers or references. Checked current public metadata also contains no retired address across 95 distinct Zenodo records, 42 KCWorks records, the OSF project/file/profile inspected, ORCID public person metadata and E-LIS 47182. This is a bounded audit. Inaccessible HCommons/PhilArchive/AfricArXiv destinations and two gone OSF GUIDs remain coverage limits, not verified clean records. The audit does not imply control of third-party indexes or all historical copies.

## Future reconciliation

Preserve permitted source evidence outside the public release when it includes retired URLs or private data. Match work and edition by DOI, title, creator, version and date. Record uncertainty and retain new catalogue identifiers. Do not infer identity from former numeric IDs. Configure a permanent redirect only if control of the old host is established and the destination is verified.

Search engines choose crawl timing, canonical selection and indexing. Submit the current sitemap through Search Console; correct metadata and working links do not guarantee ranking or removal of historical search results.
